# Examples

React Fusion is highly versatile. Here are some examples of how to integrate it into various application architectures.

## Todo App

A simple full-stack Todo application using React Fusion for data fetching and mutations.
[View Source Code on GitHub &rarr;](https://github.com/SUMANKAYALS/react-fusion/tree/main/examples/todo-app)

## Authentication App

An example demonstrating the built-in JWT authentication, HTTP-only cookies, and `protectedRoute` RBAC.
[View Source Code on GitHub &rarr;](https://github.com/SUMANKAYALS/react-fusion/tree/main/examples/auth-app)

## Dashboard App

A complex dashboard utilizing `useServer` for concurrent data fetching, heavy caching with `cacheTTL`, and the Devtools panel for monitoring.
[View Source Code on GitHub &rarr;](https://github.com/SUMANKAYALS/react-fusion/tree/main/examples/dashboard)

## MongoDB Integration

Example showing how to inject a Mongoose connection inside a global middleware and pass it via `getContext()`.
[View Source Code on GitHub &rarr;](https://github.com/SUMANKAYALS/react-fusion/tree/main/examples/mongodb)

## Prisma Example

End-to-end type safety from the Prisma schema all the way to the React UI using React Fusion's generated client.
[View Source Code on GitHub &rarr;](https://github.com/SUMANKAYALS/react-fusion/tree/main/examples/prisma)
