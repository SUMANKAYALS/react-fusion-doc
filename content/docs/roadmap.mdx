# Roadmap

React Fusion is actively maintained and continuously evolving. Here is our roadmap for the upcoming major releases.

## v3.1 (Current Focus)
- Add native WebSocket support for Realtime data subscriptions.
- Expose raw Response objects for easier file downloads/uploads.
- Optimize the `CacheManager` with a Redis adapter.

## v4.0
- **React Server Components (RSC) Integration**: Seamless interop between `server()` functions and Next.js App Router Server Components.
- Complete overhaul of the Vite Proxy to support deeper nesting.

## v5.0
- Framework Agnostic Backend: Decouple the `Runtime` to run on Bun, Deno, and Cloudflare Workers natively without Node.js polyfills.
